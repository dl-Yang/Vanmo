# Vanmo Mac 新版 TODO 与实施计划

> 基线文档：`doc/vanmo-mac-ios-parity-plan.md`  
> 生成时间：2026-07-07  
> 口径：本文件只根据 parity plan 重新制定，不沿用旧版 `mac-todo.md` 的阶段结构或历史估算。

## 1. 当前判断

Vanmo Mac 当前已经具备核心 MVP 主链路：添加连接、浏览或扫描、媒体库聚合、搜索、详情、播放、进度和收藏、设置偏好。后续工作不再以“补基础骨架”为主，而应转为“发布收口 + iOS 已产品化能力补齐 + 真实账号/设备验证 + Mac 桌面增强”。

### 1.1 完成度基线

| 范围 | 当前估算 | 后续策略 |
|------|----------|----------|
| 核心 MVP 链路 | 85%–90% | 优先验证、修边界、补 CI |
| iOS 已产品化功能 parity | 70%–80% | 补字幕配置等延后项 |
| 全量需求 parity | 60%–70% | 高级协议、原盘、下载中心分专项推进 |
| 发布可用度 | 65%–75% | CloudKit Release、真实账号、端到端回归优先 |

### 1.2 优先级定义

| 优先级 | 定义 |
|--------|------|
| P0 | 发布前必须完成，阻断 MVP 或核心可信度 |
| P1 | iOS parity 或稳定性关键项，建议进入下一迭代 |
| P2 | 体验增强或高级能力，可在稳定后推进 |
| P3 | 中长期产品增强，不阻塞当前发布 |

## 2. 立即执行：MVP 发布前收口

目标：把已完成的 Mac 主链路从“开发完成”推进到“可发布、可验收”。

### 2.1 P0 发布质量

| ID | 任务 | 验收标准 | 状态 |
|----|------|----------|------|
| MVP-1 | 跑通 `Vanmo-macOS` xcodebuild / CI | macOS target 能在 CI 或本地标准命令稳定构建 | [ ] |
| MVP-2 | 验证 macOS Release CloudKit entitlement | Release 构建带正确 iCloud/CloudKit 配置，不影响 Debug 签名 | [ ] |
| MVP-3 | 验证 iOS ↔ Mac 双端同步 | SavedConnection、FolderBookmark、CloudMediaState 可双向同步 | [ ] |
| MVP-4 | 增加或接入双端 schema 一致性检查 | CloudKit/SwiftData 同步对象范围不意外扩大 | [ ] |
| MVP-5 | 核心端到端回归 | 本地文件夹、SMB/WebDAV、Emby/Jellyfin/Plex 至少各跑通一条主路径 | [ ] |

### 2.2 P1 体验可信度

| ID | 任务 | 验收标准 | 状态 |
|----|------|----------|------|
| MVP-6 | 核对字幕配置入口 | OpenSubtitles API Key 可保存、测试，播放器在线字幕能读取同一凭据 | [ ] |
| MVP-7 | 回归 KSPlayer / FFmpeg 特殊格式路径 | MKV 等常见 AVFoundation 不支持格式可走替代引擎；ISO/MPLS/BDMV 不支持时提示明确 | [ ] |
| MVP-8 | 统一错误和空状态文案 | 无连接、空目录、认证失败、OAuth 未配置、播放失败都有可理解提示 | [ ] |
| MVP-9 | 回归 macOS 桌面交互 | 右键菜单、Quick Look、拖拽播放、菜单栏控制、快捷键可用且不互相冲突 | [ ] |
| MVP-10 | 回归设置联动 | 播放、字幕、媒体库、外观、缓存等偏好能影响对应功能 | [ ] |

### 2.3 MVP 出口标准

- 用户能添加本地文件夹、SMB/WebDAV、Emby/Jellyfin/Plex 中至少一种来源并进入内容。
- 用户能浏览目录或媒体库、进入详情、播放视频。
- 播放进度、收藏、书签能按设计同步；不能同步的来源有明确边界。
- 字幕、倍速、全屏、快捷键、自动下一集在常见 AVPlayer 路径下可用。
- Debug 和 Release 的 CloudKit 行为符合签名、账号和数据安全规则。
- 对未支持协议、未配置 OAuth、特殊格式失败不做错误承诺。

## 6. 不进入当前追赶优先级的能力

以下能力不阻塞当前 Mac MVP，也不应在没有专项设计前零散实现：

- 115、夸克、MEGA 的非官方接口。
- FTP/SFTP/NFS/DLNA 的壳入口之外的完整产品化。
- 完整 ISO、蓝光菜单、libbluray、UDF。
- Trakt 同步。
- TMDb 独立刮削。
- 后台下载中心。
- tvOS。

## 8. 回归检查清单

每次完成一个任务组后，至少回归以下路径：

- 添加连接 → 浏览目录 → 播放视频 → 关闭播放器 → 继续观看出现进度。
- 扫描目录 → 首页出现扫描库 → 进入详情 → 收藏 → iOS/Mac 状态一致。
- 搜索本地库和媒体服务器 → 点击结果 → 详情或播放行为正确。
- 修改设置中的倍速、字幕样式、自动下一集 → 播放器读取新配置。
- 删除连接 → 关联书签和扫描项被清理，不影响其他连接。
- OAuth 未配置、认证失败、播放失败、特殊格式不支持时文案清晰。
