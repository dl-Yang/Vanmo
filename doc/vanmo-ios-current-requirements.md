# Vanmo iOS 当前功能需求文档

本文档整理 Vanmo iOS 当前已实现、已产品化、占位和待验证的功能范围，作为后续从零推进 macOS 独立版本时的产品需求基线。

---

## 1. 文档目标

### 1.1 背景

Vanmo 当前主产品是 iOS App。macOS 后续希望与当前 iOS 开发隔离，从零开始推进，不直接基于现有 iOS 代码复用。因此需要先把 iOS 现有功能沉淀为清晰、完整、可验收的需求文档。

### 1.2 用途

本文档用于：

- 描述 Vanmo iOS 当前真实产品能力。
- 为 macOS 新项目提供功能对齐清单。
- 明确哪些能力已经闭环，哪些只是占位或协议实现。
- 明确播放器、媒体库、连接、同步、设置等核心规则。
- 为后续拆分 macOS 里程碑、排期和验收提供依据。

### 1.3 范围

本文档覆盖：

- iOS App 信息架构。
- 媒体源与连接类型。
- 文件浏览、扫描、媒体库、搜索。
- 播放器、字幕、PiP、HDR、原盘能力。
- 云同步、多端状态、设置项。
- OAuth、官方网盘、媒体服务器、IPTV、本地文件夹。
- 已知占位、未验证和后续待办。

本文档不覆盖：

- macOS 新项目技术架构设计。
- tvOS 适配。
- 新功能创意扩展。
- 代码级实现细节和类图。

## 2. 产品定位

### 2.1 产品概述

Vanmo 是一个面向个人媒体库和多来源媒体播放的 iOS App，核心目标是：

- 连接多种本地、局域网、云盘、媒体服务器和 IPTV 来源。
- 浏览远程目录或服务端媒体库。
- 将可扫描来源整理为本地媒体库。
- 提供统一播放体验，包括字幕、进度、收藏、在线字幕和基础元数据。
- 在 iCloud 可用时同步连接配置、书签和非媒体服务器播放状态。

### 2.2 当前主平台

| 平台 | 状态 |
|------|------|
| iOS | 主产品，功能最完整 |
| macOS | 仅基础骨架，后续独立推进 |
| tvOS | 未做，当前不在范围 |

### 2.3 最小产品价值

Vanmo iOS 的核心价值由以下闭环组成：

1. 添加媒体来源。
2. 浏览文件或媒体库。
3. 扫描并组织媒体。
4. 搜索和快速回到内容。
5. 播放视频。
6. 管理字幕、播放进度和收藏。
7. 在多端同步非敏感状态。

## 3. 信息架构

### 3.1 顶层导航

iOS App 当前采用四个底部 Tab：

| Tab | 用户含义 | 主要职责 |
|-----|----------|----------|
| 媒体库 | 首页 / Library | 展示继续观看、收藏、书签、媒体服务器虚拟库、扫描库 |
| 文件 | Browser / Connections | 管理连接、添加连接、浏览远程/本地目录 |
| 搜索 | Search | 聚合搜索本地库、媒体服务器和部分文件协议 |
| 设置 | Settings | 管理同步、播放、字幕、媒体库、元数据、外观、缓存和关于 |

### 3.2 全局播放器入口

- 用户从媒体库、搜索结果、文件浏览、IPTV 频道等入口点击播放。
- iOS 使用全屏播放器呈现。
- 播放器关闭后回到原入口页面。
- 播放过程中更新播放进度，符合条件时写回本地库和云同步状态。

### 3.3 页面层级

#### 媒体库

媒体库应包含：

- 继续观看。
- 收藏内容。
- 文件夹书签。
- Emby / Jellyfin 虚拟文件夹。
- Plex 或其他扫描来源导入后的电影库、剧集库。
- 扫描库列表。
- 媒体详情页。
- 剧集详情页。
- 收藏列表页。
- 媒体服务器文件夹页。

#### 文件

文件 Tab 应包含：

- 连接卡片列表。
- 添加连接入口。
- 编辑连接。
- 删除连接。
- 重连连接。
- 强制全量重扫。
- 当前目录浏览。
- 目录返回上级。
- 当前目录同步。
- 文件夹书签添加/取消。
- IPTV 频道列表展示。

#### 搜索

搜索页应包含：

- 搜索输入。
- 本地媒体库搜索。
- 媒体服务器 live API 搜索。
- 部分文件协议远程目录搜索。
- 按来源分组展示。
- 结果去重。
- 点击结果播放或进入详情。

#### 设置

设置页应包含：

- 云同步。
- 播放。
- 音频。
- 字幕。
- 媒体库。
- 元数据。
- 外观。
- 存储。
- 关于。

## 4. 连接与媒体源需求

### 4.1 连接模型

每个连接应至少包含：

- 连接 ID。
- 连接名称。
- 连接类型。
- 主机、端口、路径、协议等连接参数。
- 用户名、密码或 token 引用。
- OAuth 凭据引用。
- 最后访问时间。
- 同步元数据。

敏感信息原则：

- 密码、OAuth access token、refresh token 不进入 CloudKit。
- OAuth 凭据存入本机 Keychain。
- CloudKit 只同步连接配置中的非敏感字段。

### 4.2 连接类型总览

| 类型 | 当前状态 | 核心能力 |
|------|----------|----------|
| 本地文件夹 | 已产品化 | 授权、浏览、递归扫描、播放 |
| SMB | 已产品化 | 浏览、扫描、播放 |
| WebDAV | 已产品化 | 浏览、扫描、播放 |
| AList | 已产品化 | WebDAV 兼容、路径规范、播放 |
| fnOS | 已产品化 | WebDAV/SMB 预设说明与兼容 |
| Emby | 已产品化 | 登录、虚拟库、播放、收藏、续播、合集 |
| Jellyfin | 已产品化 | 同 Emby |
| Plex | 已产品化 | Plex 账号认证并内部保存 `X-Plex-Token`、分页导入、播放、搜索 |
| IPTV | 已产品化 | M3U 解析、频道分组、EPG、直播播放 |
| 百度网盘 | 合规占位 + 基础浏览/播放 | OAuth、列表、播放前解析，不自动扫库 |
| Google Drive | 协议已实现，待端到端验证 | OAuth、浏览、取流、下载、refresh |
| OneDrive | 协议已实现，待配置和验证 | OAuth、Graph 浏览、取流、下载 |
| Box | 协议已实现，待配置和验证 | OAuth、浏览、取流、下载 |
| pCloud | 协议已实现，待配置和验证 | OAuth、数据中心识别、浏览、取流 |
| Yandex.Disk | 协议已实现，待配置和验证 | OAuth、浏览、取流、下载 |
| 115 网盘 | 合规占位 | 入口和提示，不提供非官方接口 |
| 夸克网盘 | 合规占位 | 入口和提示，不提供非官方接口 |
| MEGA | 合规占位 | 需官方 SDK 深度评估 |
| FTP / SFTP | 壳实现 | 当前无真实列表和播放能力 |
| NFS / DLNA | 壳实现 | 当前无真实列表和播放能力 |

### 4.3 添加连接需求

添加连接页应支持：

- 按连接类型展示不同表单。
- 对本地文件夹触发系统文件夹选择。
- 对 OAuth 网盘展示登录按钮。
- 对未配置 OAuth 凭据的网盘展示明确配置提示。
- 对合规占位网盘展示不可用原因。
- 对 WebDAV/AList/fnOS 提供路径、协议和端口说明。
- 对 IPTV 支持播放列表 URL。
- 对媒体服务器支持服务器地址、用户名、密码或 token。

### 4.4 连接行为

连接成功后应根据类型执行不同动作：

| 类型 | 连接后行为 |
|------|------------|
| 本地文件夹、SMB、WebDAV、AList、fnOS、OAuth 网盘 | 可递归扫描并写入本地媒体库 |
| Emby、Jellyfin | 不做本地递归扫描，首页走服务端虚拟库 API |
| Plex | 使用服务端 API 分页导入媒体 |
| IPTV | 下载并解析 M3U/M3U8，不写入电影/电视剧媒体库 |
| 百度网盘 | 仅连接和浏览，不自动递归扫库 |
| 合规占位协议 | 连接时抛出明确不支持提示 |

### 4.5 删除连接需求

删除连接时应：

- 删除对应连接配置。
- 清理该连接关联的文件夹书签。
- 清理或隐藏该连接下的本地扫描媒体项。
- 不删除其他连接的数据。
- 不删除 Keychain 中无关凭据。

## 5. 文件浏览需求

### 5.1 基础浏览

文件浏览应支持：

- 展示当前连接名称。
- 展示当前路径。
- 进入文件夹。
- 返回上级目录。
- 点击可播放文件开始播放。
- 显示空目录状态。
- 显示加载状态和错误提示。
- 支持刷新当前目录。

### 5.2 文件类型识别

应识别：

- 视频文件。
- 字幕文件。
- 文件夹。
- IPTV 频道。
- 普通不可播放文件。

### 5.3 当前目录同步

对支持扫描的协议，用户可在当前目录触发同步：

- 递归扫描当前目录。
- 将视频写入本地媒体库。
- 保留连接来源信息。
- 避免重复导入。

限制：

- 百度网盘不支持当前目录递归同步。
- IPTV 不作为普通视频目录扫描。
- 媒体服务器不走文件目录递归扫描。

### 5.4 文件夹书签

用户应能：

- 在文件夹上添加书签。
- 取消书签。
- 在媒体库首页看到书签。
- 点击书签恢复连接并跳转到目标路径。
- 删除连接时清理其书签。

## 6. 媒体库需求

### 6.1 媒体项模型

媒体项应记录：

- 标题。
- 原始文件名。
- 媒体类型：电影、剧集、其他。
- 来源连接 ID。
- 来源连接类型。
- 远程路径或服务器 ID。
- 文件 URL 或播放 URL。
- 海报、背景图、标题图。
- 年份、类型、地区、简介。
- 演员、导演。
- 播放进度。
- 总时长。
- 收藏状态。
- HDR 标记。
- 字幕偏好。
- 云同步标记。

### 6.2 扫描规则

扫描应满足：

- 递归目录扫描。
- 最大深度限制，避免无限递归。
- 批量写入，避免大目录卡顿。
- 按连接和路径去重。
- 支持电影和剧集文件名识别。
- 支持电视剧按剧名、季、集聚合。
- 支持跳过不可播放文件。
- 对异常目录或文件不中断整个扫描。

### 6.3 首页分区

媒体库首页应展示：

#### 继续观看

- 展示有播放进度且未看完的内容。
- 按最近播放排序。
- IPTV 直播不进入继续观看。

#### 收藏

- 展示用户收藏的电影、剧集或媒体服务器条目。
- 支持进入完整收藏列表。

#### 文件夹书签

- 展示常用文件夹入口。
- 点击后跳转文件页并恢复对应连接路径。

#### 媒体服务器虚拟库

- Emby/Jellyfin 应展示服务端虚拟文件夹。
- 支持进入文件夹列表。
- 支持从服务端拉取继续观看和收藏。

#### 扫描库

- 对本地文件夹、SMB、WebDAV、AList、fnOS、Plex 和已扫描云盘展示扫描库。
- 电影和剧集应合理分组。
- 剧集应支持进入剧集详情页。

### 6.4 媒体详情页

媒体详情页应展示：

- 海报。
- 背景图。
- 标题。
- 年份。
- 类型。
- 地区。
- 评分或角标。
- HDR 标记。
- 简介。
- 演职员。
- 所属合集。
- 播放按钮。
- 收藏按钮。
- 继续播放状态。
- 元数据刷新入口。

### 6.5 收藏需求

收藏应支持：

- 本地扫描媒体收藏。
- Emby/Jellyfin 服务端收藏同步。
- Plex 收藏状态展示或同步能力按服务端能力处理。
- 收藏列表页分类展示电影和剧集。

规则：

- 媒体服务器条目以服务器为准，不进入 CloudKit 的本地收藏同步。
- 非媒体服务器条目可通过 `CloudMediaState` 同步收藏状态。

## 7. 搜索需求

### 7.1 搜索范围

搜索应覆盖：

| 来源 | 搜索方式 |
|------|----------|
| 本地扫描媒体库 | 本地 SwiftData 匹配 |
| Emby / Jellyfin / Plex | 服务端 live API |
| SMB / WebDAV / AList / fnOS / 本地文件夹 | 远程目录浅层 BFS 文件名搜索 |

当前不完整覆盖：

- OAuth 网盘主要依赖先扫描入库后的本地搜索。
- 百度网盘不参与远程 live 搜索。
- IPTV 不参与全局搜索。
- 占位协议不参与搜索。

### 7.2 搜索匹配字段

本地搜索当前应匹配：

- 标题。
- 原始标题。
- 导演。
- 演员。
- 类型。

待补齐匹配：

- 原始文件名。
- 来源名称。

### 7.3 搜索结果展示

搜索结果应：

- 按来源分组。
- 合并重复项。
- 展示来源标识。
- 展示海报或默认图标。
- 点击后播放或进入详情。
- 无结果时展示空状态。
- 出错时展示非阻塞错误。

## 8. 播放器需求

### 8.1 播放入口

播放器应支持从以下入口打开：

- 媒体库首页。
- 媒体详情页。
- 文件浏览页。
- 搜索结果。
- 收藏列表。
- 继续观看。
- IPTV 频道。
- 书签恢复后的目录文件。

### 8.2 播放引擎选择

播放器应根据文件类型选择引擎：

| 类型 | 推荐引擎 |
|------|----------|
| MP4 / MOV / HLS 等原生格式 | AVFoundation |
| MKV 等 FFmpeg 容器 | KSPlayer |
| IPTV HLS | AVFoundation |
| BDMV / MPLS | KSPlayer 路径 |
| ISO / 远程原盘 | 暂时 fallback，并显示能力提示 |

### 8.3 基础播放控制

播放器应支持：

- 播放 / 暂停。
- 快进 / 快退。
- 拖动进度。
- 当前时间和总时长展示。
- 亮度调节。
- 倍速切换。
- 自动隐藏控制层。
- 关闭播放器。

当前需标记为待验证或待补齐：

- 音量手势已有提示层和状态更新，但实际音量是否传入播放引擎需验证。
- 锁定控制层不应作为当前已闭环能力，后续若需要可单独产品化。

### 8.4 播放进度

播放进度规则：

- 普通视频应记录进度。
- 进度用于继续观看。
- 播放接近结束时可视为已看完。
- IPTV 直播不记录断点续播。
- 媒体服务器条目以服务端进度为准。
- 非媒体服务器条目可通过 CloudKit 同步到其他设备。

### 8.5 自动下一集与断点续播设置

当前设置页已提供：

- 设置中开启或关闭自动播放下一集。
- 设置中开启或关闭断点续播。

当前边界：

- 播放进度记录与继续观看已存在。
- 自动下一集完整消费链路需要继续接入或端到端验证。
- 断点续播开关是否参与播放起始位置判断需要继续验证。
- 直播不应进入自动下一集或断点续播逻辑。

### 8.6 倍速

播放器应支持：

- 默认播放速度设置。
- 播放时调整速度。
- 长按临时加速。
- 设置变更对后续播放生效。

### 8.7 音轨和章节

播放器应支持：

- 展示可用音轨。
- 切换音轨。
- 展示章节列表。
- 点击章节跳转。
- BDMV / MPLS 解析出的章节应进入章节列表。

### 8.8 字幕

#### 字幕来源

应支持：

- 内嵌字幕。
- 同目录外挂字幕。
- 在线字幕搜索下载。

#### 字幕格式

应支持：

- SRT。
- VTT。
- ASS / SSA。

规则：

- SRT/VTT 可走通用解析和 SwiftUI overlay。
- ASS/SSA 优先走 KSPlayer 富字幕能力。
- 当当前引擎不支持 ASS/SSA 时应明确提示，不应错误当作普通字幕解析。

#### 字幕设置

应支持：

- 字幕开关。
- 字幕轨选择。
- 字幕延迟。
- 字号。
- 字幕颜色。
- 背景颜色。
- 字幕位置。
- 首选语言。
- 字幕偏好持久化。

#### 在线字幕

应支持：

- OpenSubtitles。
- 搜索结果展示。
- 下载并缓存。
- 下载后加入可选字幕轨。

OpenSubtitles 应支持：

- API Key 配置。
- 账户登录测试。
- 凭据安全保存。

当前边界：

- Shooter、Subhd 已有 Provider 注册壳，但缺少产品化配置入口和默认可用 endpoint，应标记为待配置/待产品化。

### 8.9 HDR

应支持：

- 从文件名启发式识别 HDR。
- 从 AVFoundation 元数据探测 HDR。
- 在详情页或播放相关 UI 展示 HDR 标记。
- 为 AVFoundation 路径做基础 EDR/HDR 输出调优。

### 8.10 PiP

应支持：

- AVFoundation 原生画中画。
- KSPlayer sample-buffer PiP 能力探测。
- KSPlayer PiP 不可用时展示明确提示。

### 8.11 硬件解码

应支持：

- 设置中开启“硬件解码优先”。
- 将设置传入 KSPlayer 解码选项。
- 硬解失败时自动软解重试。
- 设置页说明该选项通常在下次加载时生效。

### 8.12 原盘与 ISO

当前应支持：

- 本地 BDMV 目录。
- 本地 `.mpls` playlist 解析。
- 主 playlist 选择。
- 章节映射。
- KSPlayer 播放 URL 解析。

当前不完整支持：

- ISO 镜像完整解析。
- 远程 BDMV 随机读完整链路。
- libbluray。
- UDF。

对于不完整支持场景，应：

- 显示明确提示。
- 尝试合理 fallback。
- 不向用户承诺完整蓝光菜单或完整 ISO 能力。

### 8.13 直播播放

IPTV 直播播放应支持：

- LIVE 标识。
- 不记录续播。
- 播放失败自动重试。
- HLS 优先走 AVFoundation。
- 失败频道在频道列表内标记不可播放。

## 13. 云同步需求

### 13.1 同步对象

CloudKit 同步应覆盖：

| 对象 | 是否同步 | 说明 |
|------|----------|------|
| SavedConnection | 是 | 仅非敏感连接配置 |
| FolderBookmark | 是 | 文件夹书签 |
| CloudMediaState | 是 | 非媒体服务器播放进度和收藏 |
| MediaItem 完整元数据 | 否 | 保留本地，避免服务器媒体污染 |
| 密码 | 否 | Keychain 本机保存 |
| OAuth token | 否 | Keychain 本机保存 |

### 13.2 同步触发

应在以下时机触发：

- App 启动。
- App 回到前台。
- 连接配置变更。
- 书签变更。
- 播放进度变更。
- 收藏状态变更。
- 用户开启或关闭同步。

### 13.3 冲突规则

应支持：

- 最近更新时间优先。
- 播放进度按合理策略合并。
- 收藏按最近写入状态合并。
- 书签按 ID 或来源路径去重。
- 连接配置避免重复。

### 13.4 构建与账号规则

Debug：

- 不带 iCloud entitlement。
- 兼容个人开发者账号。
- 设置页禁用 iCloud 同步并解释原因。

Release：

- 带 CloudKit entitlement。
- 定义 `CLOUDKIT_SYNC_ENABLED`。
- 支持 CloudKit-backed SwiftData。
- 需要付费开发者账号和正确 iCloud container。

### 13.5 同步边界

不同步：

- Emby / Jellyfin / Plex 的播放进度和收藏。
- 密码。
- OAuth access token。
- OAuth refresh token。
- 本地完整媒体库元数据。

## 17. 安全与合规需求

### 17.1 凭据安全

应满足：

- 密码不进入 CloudKit。
- OAuth token 不进入 CloudKit。
- OAuth 凭据存入 Keychain。
- 日志不输出 token、cookie、密码。
- 设置和错误提示避免泄露敏感 URL 参数。

### 17.2 网盘合规

应满足：

- 官方网盘只使用开放平台 OAuth/API。
- 不使用 Cookie 登录。
- 不使用抓包接口。
- 不使用逆向私有接口。
- 对未开放能力明确提示“暂不支持”。

### 17.3 远程取流安全

应满足：

- 跨 host 302 时避免错误携带原始 Authorization。
- Google Drive 等 Bearer 取流需要在 Range 请求中持续带 token。
- 百度网盘按官方要求注入 UA 或必要头。

## 18. 错误与空状态需求

### 18.1 连接错误

应展示明确错误：

- 认证失败。
- 路径不存在。
- OAuth 未配置。
- OAuth 登录取消。
- token 过期。
- 当前协议未实现。
- 官方能力暂未开放。

### 18.2 媒体库空状态

应展示：

- 尚未添加连接。
- 连接未扫描到视频。
- 当前筛选无结果。
- 收藏为空。
- 继续观看为空。

### 18.3 播放错误

应展示：

- 文件不可播放。
- 取流失败。
- 字幕加载失败。
- 当前引擎不支持该字幕格式。
- 原盘/ISO 能力不完整。
- IPTV 断流重试失败。

## 21. 验收标准总表

### 21.1 连接验收

- 能添加、编辑、删除连接。
- 能区分已支持、待配置、占位和未实现协议。
- 连接失败有明确错误。
- 删除连接不影响其他来源。

### 21.2 浏览验收

- 能进入目录。
- 能返回上级。
- 能刷新。
- 能播放可播放文件。
- 能添加文件夹书签。
- 空目录和错误状态清晰。

### 21.3 扫描验收

- 支持递归扫描。
- 扫描不会重复导入。
- 电影和剧集能正确进入媒体库。
- 大目录不会阻塞 UI。
- 不支持扫描的协议有明确提示。

### 21.4 媒体库验收

- 首页展示继续观看、收藏、书签、媒体库分区。
- 媒体详情展示完整基本信息。
- 剧集能聚合。
- 收藏状态可切换。
- 媒体服务器与扫描库来源逻辑不混乱。

### 21.5 搜索验收

- 搜索本地库。
- 搜索媒体服务器。
- 搜索部分文件协议。
- 结果按来源分组。
- 点击结果行为正确。

### 21.6 播放验收

- 能播放本地和远程视频。
- 能记录进度。
- 能恢复播放。
- 能切字幕。
- 能调倍速。
- 能处理直播。
- 播放错误可理解。

### 21.7 同步验收

- Release 下连接、书签、非媒体服务器播放状态可同步。
- Debug 下不会因 iCloud entitlement 签名失败。
- 密码和 token 不进入云端。
- 媒体服务器状态不被 CloudKit 覆盖。
