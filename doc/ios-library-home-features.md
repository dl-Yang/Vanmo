# Vanmo iOS 首页 Library 功能整理

本文档简要整理 Vanmo iOS 底部 Tab 中「媒体库 / Library」首页的主要功能，作为产品和后续平台对齐参考。

---

## 1. 页面定位

Library 是 Vanmo iOS 的首页型媒体聚合页，用于把用户最常访问的内容集中展示：

- 继续观看。
- 收藏内容。
- 文件夹书签。
- Emby / Jellyfin 媒体库。
- 本地扫描后的电影、电视剧库。

用户可以从这里快速回到播放、进入收藏列表、查看某个媒体库的全部内容，或跳转到文件页继续浏览来源。

---

## 2. 入口与整体结构

Library 位于 App 底部 Tab 的第一个入口，页面标题显示为「首页」。

页面采用自定义首页视觉风格，支持明暗模式适配。背景会优先使用最近播放内容的海报或背景图做模糊层；如果没有最近播放，则使用收藏内容的海报。主要内容按以下顺序展示：

1. 顶部标题与同步状态。
2. 继续观看。
3. 收藏入口。
4. 文件夹书签。
5. Emby / Jellyfin 媒体库。
6. 扫描媒体库。

当没有任何连接、历史、收藏、书签和媒体库内容时，页面展示空状态，并引导用户去添加服务器或媒体来源。

---

## 3. 主要功能

### 3.1 继续观看

展示最近播放过的媒体内容，包含海报、标题和播放进度。用户点击后可直接进入播放器继续播放。当前 UI 区块标题为「历史记录」。

### 3.2 收藏

首页展示收藏内容的概览卡片，并显示收藏总量。点击后进入收藏列表页。

收藏列表支持：

- 按全部、电影、剧集等类型筛选。
- 搜索收藏内容。
- 下拉刷新。
- 编辑并取消收藏。
- 进入媒体详情页。

### 3.3 文件夹书签

展示用户在文件浏览中保存的文件夹书签。点击书签后会切换到「文件」Tab，并请求打开对应文件夹，方便快速回到常用目录。

### 3.4 Emby / Jellyfin 媒体库

对 Emby 和 Jellyfin 连接，首页会按服务器展示媒体库文件夹，只显示适合首页展示的电影库和电视剧库。

每个媒体库卡片包含：

- 媒体库名称。
- 来源服务器名称。
- 部分内容预览。
- 「查看全部」入口。

点击「查看全部」后进入媒体库二级列表，列表支持分页加载。点击媒体项会进入详情页或继续浏览子文件夹，电影和单集可通过上下文菜单直接播放。

### 3.5 扫描媒体库

对 SMB、FTP、WebDAV 等可扫描来源，Library 会展示扫描后整理出的电影和电视剧虚拟库。

扫描库与 Emby / Jellyfin 的展示形式基本一致，但数据来自本地 SwiftData 聚合结果，而不是服务端媒体库 API。

### 3.6 同步反馈

页面会展示媒体库同步状态：

- 顶部状态胶囊显示已同步的媒体源和库数量。
- 同步进行中时显示同步提示浮层。
- 同步完成后显示 Toast。

当用户新增连接或媒体库扫描完成后，Library 会刷新首页数据。

---

## 4. 导航与播放

Library 相关的主要导航路径：

- 点击继续观看内容：直接打开播放器。
- 点击收藏概览：进入收藏列表。
- 点击文件夹书签：切换到文件页并打开目标文件夹。
- 点击媒体库「查看全部」：进入该库的内容列表。
- 点击电影或剧集：进入媒体详情页。
- 点击可继续浏览的文件夹、合集、季：进入下一级浏览页。
- 点击扫描库中的电视剧：进入扫描剧集详情页。

播放器由全局状态统一管理，以全屏方式呈现。

---

## 5. 关键规则

- 首页只展示电影和电视剧类型的媒体库，隐藏播放列表等其他类型。
- 已确认为空的媒体库不会继续显示在首页。
- 页面首次进入时加载本地数据，并在后台刷新 Emby / Jellyfin 首页数据。
- App 本次启动内会尽量避免重复拉取首页 live 数据，减少页面闪烁和网络请求。
- 收藏变更、连接同步完成、回到 Library Tab 等场景会触发不同粒度的刷新。
- 单个服务器连接失败不会阻断其他服务器内容展示。

---

## 6. 当前未接入或弱化的能力

以下能力在代码中已有字段或占位，但当前 Library 首页没有作为主要功能开放：

- 首页搜索按钮目前被隐藏。
- 首页筛选条件字段存在，但未绑定到首页 UI。
- 独立的「继续观看二楼」页面目前未接入首页。
