# 媒体详情 UI 设计改版
## 交互实现
- **沉浸海报**：进入详情页展示**全屏沉浸式海报**，中间靠底部居中显示标题
- **景深联动**：在顶部如果向下滑动海报**跟随手势进行景深**动画联动
- **嵌套滑动**：向上滑动时，实现类似 Andorid coordinatorlayout + toolbar 效果的联动效果：海报跟随手势进行**景深动画**，同时随着手势滑动从屏幕底部出现`媒体信息`内容，同样跟随手势呼出。**当滑动到固定的高度（3/4）个屏幕时将会固定住海报和媒体信息布局**，此时滑动手势将被`媒体信息布局`接管，所有滑动都将只滑动`媒体信息布局`。当向下滑动到`媒体信息部局顶部`无法再滑动时，滑动手势将会返回给**父布局**继续向下滑动直到`媒体信息布局`被收起。

## 海报背景
- 首次进入媒体详情页沿用当前的加载逻辑：先加载缓存好的缩略图并添加毛玻璃效果，然后等待无损海报加载完成后覆盖替换

## 媒体信息
- 整个媒体信息布局按现在的布局保持不变。
-【媒体信息】背景变为纯色，跟随系统变化。
- 整个形状变为顶部圆角矩形

## 其他
- 交互实现描述中的手势滑动状态可以理解为**收起**，**展开**和**滑动**三种形态:
    1. 刚进入详情页时媒体信息**收起**不可见，但是会有指示器在屏幕底部以提示用户可以向上滑动
    2. 滑动到约定高度（屏幕的 3/4）时称为**展开**状态。
    3. 其他时候为**滑动**形态
- **三种状态都需要生成设计稿**
- 沿用Figma Vanmo 项目中`Vanmo (iOS · Dark)`的设计风格，并补全Light 模式下的界面
