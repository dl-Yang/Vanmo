> **回复语言规则**：本仓库的所有交互默认使用中文。模型的所有思考过程与回复内容均必须使用中文（代码、命令、文件名、术语等原文除外）。

Vanmo is a video player app: iOS app (`Vanmo` target) + macOS app (`Vanmo-macOS` target) sharing a local Swift package (`VanmoCore`). SwiftUI, MVVM, Swift Concurrency, SwiftData. Min iOS 17 / macOS 14 (per `project.yml`; README's "iOS 16.0" is stale).

## Build system (important)

- The Xcode project is **generated by XcodeGen** from `project.yml` (committed). Edit `project.yml` for target/settings/dependency changes, then run `xcodegen generate` and commit the regenerated `Vanmo.xcodeproj/project.pbxproj`. Never hand-edit the pbxproj.
- Build & run without opening Xcode: `./run_device.sh` (default iOS device; `--simulator`, `--macos`, `--configuration Release`, `--clean` if SPM resolution gets stuck, `--launch-only`). Uses `./build/DerivedData`.
- Release IPA: `./build_ipa.sh` (archive + export to `build/ipa/`).
- Tests live only in `Packages/VanmoCore/Tests/` (no test target in the xcodeproj). Run with `swift test` from `Packages/VanmoCore`.

## Directory layout

- `Vanmo/` — iOS app (App/, Core/, Features/, Shared/, Resources/). macOS target sources come from `VanmoMac/` (plus two shared views pulled from `Vanmo/Shared/Components/` per `project.yml`).
- `Packages/VanmoCore/` — shared domain layer: SwiftData models, storage/scanning (`ModelContainerFactory`, `MediaScanner`), network services (SMB/WebDAV), subtitle parsing, metadata. iOS UI code must not live here.
- `doc/ai/` — authoritative architecture docs: `player-architecture.md` (dual engine: AVPlayerEngine native vs KSPlayerEngine FFmpeg), `player-buffering.md`, `metadata-cache.md`, `swift-coding.md`. `todos.md` is the feature roadmap.

## Conditional compilation

- `FFMPEG_ENABLED`: defined for both app targets; requires `Vanmo/Frameworks/FFmpeg/` — gitignored, built with `scripts/build-ffmpeg-ios.sh` (FFmpeg 7.1, takes a while). Builds fail without it.
- `CLOUDKIT_SYNC_ENABLED`: **Release only**. CloudKit/iCloud sync is Release-only; Debug builds use non-cloud entitlements. Don't add CloudKit code paths expecting them in Debug.

## Conventions (existing instruction sources — follow them)

- Swift/style rules: `.cursor/rules/swift-coding.mdc` (also mirrored in `.agents/rules/`): View `body` ≤ 40 lines, every View gets `#Preview`, prefer `@Observable`, no force unwrap, default `private`.
- Device debugging: `.cursor/rules/ios-device-debug-logs.mdc` (alwaysApply) — debug via local console logs only (`print`/`os.Logger`/`NSLog`), **never** remote logging/telemetry instrumentation; wrap temp logs in `#if DEBUG`, remove after fixing.
- UI work: load `.agents/skills/figma-design-fidelity` — Figma is the design source of truth; icons via better-icons MCP (Iconify), Lottie animations via lottiefiles-creator MCP.
- Git: origin is `git@github.com:dl-Yang/Vanmo.git`, main branch. Commit messages historically Chinese/free-form; `.codex/skills/git-workflow` prescribes conventional commits.
